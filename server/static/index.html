Connection

Create the token in Home Assistant under your profile → Security → Long-lived access tokens. The WiFi password and token are stored only in the local database and written into the generated config.h at build time; neither is committed to git. The bridge announces itself as rc-bridge.local; enter its IP instead if that name does not resolve on your network.

Installed bridge

checking…

Once the bridge is running firmware 1.1.0 or newer it updates over WiFi: the server compiles the sketch with the current settings and mappings and pushes it to the bridge, which reboots into it. The very first install of that firmware has to go over USB.

Button actions
